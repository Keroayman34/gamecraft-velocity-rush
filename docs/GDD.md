# Game Design Document — Velocity Rush

**Version:** 0.1 skeleton  
**Status:** Not yet complete; concept decisions are provisional.

## 1. Game overview
Velocity Rush is a 3D skill-based driving game structured around a global championship. Players master speed, braking, cornering, drifting, jumps, and precision driving.

## 2. Approved initial direction
- Championship mode
- Simcade driving
- Global world identity
- Landscape orientation
- Single-player initially
- 10 planned vehicles
- Cinematic Motorsport visual direction with balanced realism

See `PROJECT_CHARTER.md` and `DECISIONS.md`.

## 4. Design rule
Do not treat illustrative examples or placeholder values as final rules. Every system must have explicit player-facing rules, edge cases, and acceptance criteria before implementation.
