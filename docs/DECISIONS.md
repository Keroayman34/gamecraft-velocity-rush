# Project Decision Register

Record decisions that materially affect the product, technology, art direction, or production workflow.

Statuses:
- `APPROVED-INITIAL`: accepted as a working direction; validation may change it.
- `APPROVED`: formally approved for implementation.
- `PROPOSED`: under discussion.
- `OPEN`: not decided.
- `REJECTED`: not to be used.

## Change procedure
For every new or changed decision, record:
- ID
- Date
- Context / problem
- Options considered
- Decision and rationale
- Consequences / risks
- Approval status

Do not silently overwrite a previous decision. Add a dated change entry.
