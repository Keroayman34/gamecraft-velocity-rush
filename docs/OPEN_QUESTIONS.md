# Open Questions — Velocity Rush

This list prevents assumptions from being mistaken for decisions.

## Product and game design
- Exact championship and event structure.
- MVP event count and content scope.
- Camera mode and whether players can switch cameras.
- Competitor AI: which events use opponents versus solo time/skill trials?
- Exact scoring formulas and star thresholds.
- Session duration targets.
- Save and progression rules.
- Final vehicle roster, names, stats, and unlock conditions.
- Economy values, upgrade levels, and balancing.

## Technical
- Exact Unity Editor version and WebGL package compatibility.
- Render pipeline choice after testing target browser performance.
- Vehicle physics implementation strategy.
- Input abstraction for keyboard and touch.
- Save strategy supported by Playgama Bridge.
- Scene organization and runtime architecture.
- Automated build and test strategy.
- Target browser/device performance budgets.

## Art and UX
- Final logo and font families/licenses.
- Approved final color tokens and contrast checks.
- Final main menu, garage, championship, HUD, results, and settings designs.
- First MVP environment.
- Production 3D vehicle asset pipeline.
- Camera composition and field of view.

## Platform and release
- Whether mobile browser support is included in first release.
- Final Playgama integration details and current requirements.
- Ad placements and frequency caps after retention testing.
- Analytics event taxonomy.

## Rule
The AI agent may research and propose options, but must not mark an open question as approved without project-owner confirmation.
