# Art Direction v0.1 — Concept Board

**Reference ID:** AD-BOARD-001  
**Board image:** `art-direction-board.png` (PNG 1672×941; verified present in this folder)  
**Status:** DRAFT / concept board — not an approved production target  
**Authoritative written direction:** [`../../ART_DIRECTION.md`](../../ART_DIRECTION.md) (Cinematic Motorsport, high-quality realistic-inspired 3D presentation)

## What this board represents
- The initial **mood and visual direction** for Velocity Rush: premium motorsport atmosphere, cinematic lighting, dark UI surfaces with red/amber accents, realistic-inspired 3D style.
- Illustrative composition, mood, palette feel, and atmosphere targets aligned with `ART_DIRECTION.md` §2–§6.
- Conceptual guidance for generating and evaluating future, more specific references.

## What this board does NOT represent
- It is **not** a final production UI specification, screen layout, or interaction design.
- It is **not** a collection of production-ready assets: not 3D models, not textures, not editable UI source files.
- It is **not** an approved color-token or typography decision (those remain provisional in `ART_DIRECTION.md` §3–§4).
- Text visible in the image is placeholder, not authoritative copy.

## How future agents should use it
1. Read `ART_DIRECTION.md` first; it governs wherever it and the board differ.
2. Treat the board as `DRAFT`: use it to understand mood and direction; do not implement any specific screen or asset from it alone.
3. When a feature needs an implementation target, request/create a feature-specific reference and specification, then obtain `APPROVED` status from the project owner (`../README.md` status rules).
