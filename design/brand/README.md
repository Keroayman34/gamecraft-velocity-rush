# Brand Documentation — GameCraft Studio / Velocity Rush

This folder documents the brand identity direction and its governance. It does **not** contain a finalized logo or brand identity — none exists yet; do not invent one.

## Logo direction (Open)
- No approved logo exists. Logo work must come from the Cinematic Motorsport direction (`../ART_DIRECTION.md`) and be produced through the reference workflow (`../references/README.md`).
- Brand and in-game naming must never reproduce existing trademarks or mimic real team/racing identities.

## Brand voice
- High-energy, confident, focused on mastery: Skill, Precision, Progress, Challenge. Realistic — inspired motorsport tone for tuned driving.

## Color identity
- Inherits the provisional palette from `../ART_DIRECTION.md` §3 (Primary Dark `#0B0D12`, Accent Red `#E10600`, Highlight Amber `#FFB400`, Text Light `#E6E6E6`, Surface `#2A2F3A`, UI Panel `#1A1F27`).
- That file is the single source of truth for color values; do not duplicate or drift the tokens here.

## Typography requirements (Open — OQ-A01)
Before any font is used commercially, verification is mandatory:
- Commercial usage license (and embedded-in-game/deployment rights).
- Arabic glyph coverage and quality.
- English glyph coverage and quality.
- Readability at UI sizes, including in RTL mirroring context.
- File size and WebGL performance impact.
- No font is production-approved until those checks pass and the project owner approves.

## Language requirements
- Arabic (RTL) and English (LTR) are the initial target languages (DECISIONS D-013).
- Arabic copy uses neutral Arabic.
- Brand copy must be written bilingually where used in UI.

## Asset licensing rules
- Every brand asset must have documented provenance and license (`AI_AGENT_GUIDELINES.md` §6).
- No copyrighted vehicle makes, team liveries, series logos, or real-world marks without proper licensing.
- Approved logo/color/typography references are stored here; unapproved concepts remain in `../references/` with DRAFT status.
